# Moiré Pattern Cryptography Protocol

### Overview
The M1 system does not use prime-factorization math for security. It uses **Physical Interference**.

### The Mechanism
1. **The Lock:** Data is etched in two misaligned nanogratings.
2. **The Key:** A phase-locked laser beam must match the Moiré fringe frequency.
3. **The Result:** Correct phase alignment produces constructive interference; incorrect phase results in destructive noise, making the data physically invisible.
